# Power Fitness Club

Power Fitness Club is a fully responsive, client-side fitness website designed to help users stay motivated, explore workout programs, plan nutrition, and use simple health and fitness tools.

The project is built with HTML, CSS, and JavaScript and includes multiple pages for fitness programs, meal plans, shopping, motivational content, contact information, and supporting resources.

## Features

- Responsive multi-page website
- Fitness program showcase
- BMI calculator
- Daily calorie calculator
- Recommended macronutrient breakdown
- Meal plan and diet plan sections
- Fitness shopping page
- Motivational quotes page
- About and contact pages
- Responsive navigation menu
- Sticky header behavior
- Scroll-based animations
- Smooth scrolling
- Interactive card and hover effects
- Font Awesome icons and external image resources

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Interactive Tools

### BMI Calculator

The home page includes a BMI calculator. Users can enter their height and weight to calculate their Body Mass Index and receive a weight-category result.

### Daily Calorie Calculator

The meal plan page includes a calorie calculator that uses:

- Gender
- Age
- Weight
- Height
- Activity level
- Fitness goal

The calculator estimates daily calorie requirements and displays a recommended macronutrient breakdown for protein, carbohydrates, and fats.

## How to Run the Project

No backend or database setup is required.

### Option 1: Open locally

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.

### Option 2: Clone with Git

```bash
git clone https://github.com/paakhiagrw-design/Power-Fitness-Website.git
cd Power-Fitness-Website
```

Then open `index.html` in your browser.

For a smoother development experience, you can also run the project using a local development server such as the VS Code Live Server extension.
